📊 Quant Dash
Sentiment Based Trading Strategy Backtester
Overview

Quant Dash is a quantitative analysis and backtesting platform built to experiment with data driven trading strategies.
This module focuses on a sentiment based trading strategy backtester, which evaluates how sentiment signals can be translated into trading decisions and measured using standard performance metrics.

The project simulates real world trading by separating signal generation, trade execution, and performance evaluation, ensuring the backtest remains realistic and interpretable.

Motivation

Market sentiment plays a critical role in short to medium term price movements.
Quant Dash explores whether sentiment signals can be systematically exploited by

• Defining clear entry and exit rules
• Backtesting on historical price data
• Measuring risk adjusted returns
• Identifying strengths and weaknesses of sentiment driven strategies
